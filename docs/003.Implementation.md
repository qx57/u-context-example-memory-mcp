# Реализация и проверка MVP

## Локальный запуск

Нужны Docker с Compose v2, JDK 21 или новее и Python 3.12. Из корня проекта соберите JAR и установите зависимости адаптера.

```bash
./mvnw clean package
python3.12 -m venv .venv
.venv/bin/python -m pip install -r requirements.txt
```

При первом запуске создайте локальный файл ключей Qdrant. Используйте ключ записи из этого файла в настройках MCP, а ключ чтения — в Dashboard.

```bash
umask 077
if [ ! -e deployment/.env ]; then
  printf 'QDRANT_API_KEY=%s\nQDRANT_READ_ONLY_API_KEY=%s\n' \
    "$(openssl rand -hex 32)" "$(openssl rand -hex 32)" > deployment/.env
fi
docker compose --env-file deployment/.env -f deployment/compose.yaml up -d
curl --fail http://127.0.0.1:6333/healthz
```

В MCP-клиенте добавьте локальный сервер типа `stdio`. Ниже пример для клиентов с форматом `mcpServers`. Подставьте абсолютные пути к Java, JAR и интерпретатору из `.venv`. Для `MCP_MEMORY_OPERATOR_TOKEN` сгенерируйте отдельное случайное значение, например командой `openssl rand -hex 32`.

```json
{
  "mcpServers": {
    "test-memory": {
      "command": "/absolute/path/to/java",
      "args": ["-jar", "/absolute/path/to/project/target/test-memory-mcp-0.1.0.jar"],
      "env": {
        "MCP_MEMORY_PYTHON": "/absolute/path/to/project/.venv/bin/python",
        "OPENAI_API_KEY": "OPENAI_PROJECT_KEY",
        "QDRANT_API_KEY": "QDRANT_WRITE_KEY",
        "MCP_MEMORY_OPERATOR_TOKEN": "LOCAL_OPERATOR_TOKEN"
      }
    }
  }
}
```

Откройте `http://127.0.0.1:8085/ui/memories`, пока MCP-клиент держит процесс запущенным. Для входа введите токен оператора. REST принимает этот же секрет как Bearer-токен. Технический просмотр Qdrant доступен на `http://127.0.0.1:6333/dashboard`. Если порт Qdrant изменён, передайте его в `MCP_MEMORY_QDRANT_URL`. Адаптер создаёт коллекцию при первом обращении и сверяет схему существующей коллекции. `GET /health` проверяет Qdrant и показывает состояние операций с провайдером по последним вызовам.

Закреплены Spring Boot 3.5.16, Spring AI 1.1.8 с MCP Java SDK 0.18.3, Mem0 OSS 2.2.1 и Qdrant с Python-клиентом 1.20.0. Сервер принимает клиентский handshake MCP `2025-11-25` через STDIO. [Spring AI 1.1 MCP Server](https://docs.spring.io/spring-ai/reference/1.1/api/mcp/mcp-server-boot-starter-docs.html)

### Настройки сервера в MCP-клиенте

| Переменная | Назначение | Значение по умолчанию |
|---|---|---|
| `OPENAI_API_KEY` | Ключ проекта OpenAI API для Responses и Embeddings. Передаётся из локальных настроек MCP-клиента в окружение сервера, затем в адаптер | Обязательное значение |
| `MCP_MEMORY_LLM_MODEL` | Точный ID модели OpenAI Responses для краткого резюме записи | `gpt-6.1-terra` |
| `MCP_MEMORY_EMBEDDING_MODEL` | Точный ID модели векторизации | `text-embedding-3-small` |
| `MCP_MEMORY_EMBEDDING_DIMS` | Размерность пространства векторов | `1536` |
| `MCP_MEMORY_PYTHON` | Абсолютный путь к интерпретатору Python в окружении адаптера | Обязательное значение |
| `MCP_MEMORY_QDRANT_URL` | Адрес локального Qdrant | `http://127.0.0.1:6333` |
| `QDRANT_API_KEY` | Ключ записи и чтения коллекции для адаптера | Обязательное значение |
| `MCP_MEMORY_COLLECTION` | Имя коллекции наблюдений | `rest_test_memory_v1` |
| `MCP_MEMORY_SEARCH_THRESHOLD` | Минимальная оценка ранжирования Mem0 от 0 до 1 | `0.1` |
| `MCP_MEMORY_SCOPE` | Постоянный идентификатор области, передаваемый в Mem0 как `user_id` | `local-workspace` |
| `MCP_MEMORY_HTTP_PORT` | Порт REST и интерфейса на `127.0.0.1` | `8085` |
| `MCP_MEMORY_OPERATOR_TOKEN` | Случайный локальный секрет для авторизации REST и входа в интерфейс оператора | Обязательное значение |

Запрошенная целевая модель — Terra 6.2. На 23 ноября 2026 года публичный каталог OpenAI указывает `gpt-6.1-terra` как актуальную модель семейства Terra. Для рабочего профиля выбран этот ID. Когда для используемого ключа станет доступен точный ID Terra 6.2, его можно указать в `MCP_MEMORY_LLM_MODEL`. Доступность проверяется пробным вызовом Responses с этим ключом. Подписка на ChatGPT и ключ API настраиваются отдельно. Векторизация использует отдельный ID модели Embeddings. [Каталог OpenAI API](https://developers.openai.com/api/docs/models) · [GPT-6.1 Terra](https://developers.openai.com/api/docs/models/gpt-6.1-terra) · [OpenAI Embeddings API](https://developers.openai.com/api/reference/resources/embeddings/methods/create)

Хранить ключ OpenAI в локальных настройках конкретного MCP-сервера, по возможности в хранилище секретов клиента. Например, клиент передаёт его через поле окружения для `OPENAI_API_KEY`. В репозитории допустимы только имена переменных. Python-процесс получает секреты OpenAI и Qdrant и собственные настройки через явно заданное окружение. `MCP_MEMORY_OPERATOR_TOKEN` остаётся в JVM. В адаптере отключить телеметрию Mem0 через `MEM0_TELEMETRY=false`. [Переменная телеметрии Mem0](https://github.com/mem0ai/mem0/blob/main/mem0/memory/telemetry.py)

## Порядок реализации

| Этап | Работы | Результат проверки |
|---|---|---|
| 1. Проверка интеграции | Поднять Qdrant. Проверить путь `Memory.add(infer=False)` → собственный Qdrant-клиент → `Memory.search` с настоящим Qdrant и тестовым провайдером эмбеддингов. Проверить настройку `insert_only`, чтение сохранённого payload и фильтры. Запустить Spring STDIO и MVC в одной JVM из целевого MCP-клиента | Работают устойчивый UUID, условия вставки и поиска, MCP и loopback HTTP. Выбраны и закреплены версии зависимостей |
| 2. Наблюдение и поиск | Ввести DTO, очистку, расчёт исхода, единый прикладной слой, адаптер, REST и два MCP-инструмента. Подключить Responses и Embeddings из конфигурации MCP-клиента | Агент находит решения перед запуском теста и сохраняет результат после запуска. REST и MCP возвращают одну и ту же запись |
| 3. Управление записями | Добавить список с фильтрами, карточку, ручную оценку, архивацию, восстановление и обработку ревизий. Защитить HTTP-маршруты и формы | Оператор корректирует исход и управляет видимостью записи. Обе оценки доступны в карточке |
| 4. Эксплуатация | Настроить диагностику, тайм-ауты, резервные копии и процедуру смены эмбеддингов. Проверить сквозной сценарий с обезличенными примерами на русском и английском | После перезапуска данные доступны. Сбои дают предсказуемые ошибки. Поиск проходит проверку релевантности |

Первый этап проверяет, что закреплённая версия Mem0 поддерживает подмену Qdrant-клиента и что SDK соблюдает область при поиске. Для `insert_only` проверить точную форму вызова SDK и сценарий, при котором ответ Qdrant теряется после вставки. Вспомогательная SQLite Mem0 должна храниться в отдельном временном каталоге с правами процесса. Предусмотреть очистку при завершении и ограничение размера через ротацию дочернего процесса между запросами.

## Проверка

Сквозной тест запускает JAR, вызывает MCP по STDIO и HTTP, использует работающий локальный Qdrant и подставляет локальный OpenAI API для Responses и Embeddings. Он создаёт отдельную временную коллекцию и проверяет первый вызов записи с потерянным подтверждением Qdrant. Для запуска из корня проекта используйте уже заполненный локальный файл Qdrant.

```bash
(
  set -a
  . deployment/.env
  set +a
  export MCP_MEMORY_QDRANT_URL="http://127.0.0.1:${QDRANT_HTTP_PORT:-6333}"
  .venv/bin/python tests/smoke.py
)
```

## Критерии приёмки

| Сценарий | Ожидаемый результат |
|---|---|
| Выполнены проверки ожидаемого HTTP 404 | Автоматическая оценка `SUCCEEDED` |
| Проверка не прошла, запуск прерван инфраструктурой, проверок нет | В трёх примерах соответственно `FAILED`, `INCONCLUSIVE`, `INCONCLUSIVE` |
| Одно наблюдение записано через MCP и повторено через REST | Один UUID, та же квитанция, одна точка в Qdrant |
| Параллельные записи с одним UUID, а также повтор после тайм-аута | Одна точка. Совпадающий вход получает квитанцию, различающийся получает `409` или MCP-ошибку конфликта |
| Повтор записи после ручной правки и архивации | Сохраняются новая ревизия, ручной исход и архивный статус |
| Семантически одинаковые записи в разных сервисах и окружениях | Возвращаются только активные записи запрошенной области, сервиса и окружения. Проверить также фильтры по маршруту и исходу |
| Изменение и снятие ручной оценки | Поиск использует новый эффективный исход. Снятие оценки возвращает автоматический исход. Вектор остаётся прежним |
| Две ручные правки с одним `ETag` | Одна правка применяется, вторая получает `412` |
| Архивация и восстановление | Запись исчезает из семантического поиска, видна в списке архива и снова участвует в поиске после восстановления |
| LLM резюме недоступна, Embeddings доступен | Запись сохраняется с текстом по шаблону, в диагностике появляется событие перехода на шаблон |
| Embeddings или Qdrant недоступны | Семантический поиск сообщает об ошибке зависимости. При доступном Qdrant список, карточка и ручная оценка работают во время сбоя OpenAI |
| Секрет во входе и вывод диагностических сообщений | Обнаруженный секрет блокируется до отправки. Ключи и полные тексты отсутствуют в логах. `stdout` обоих процессов содержит только сообщения их протоколов |
| Перезапуск и восстановление из снимка | ID, текст, оценки, ревизии и поиск сохранены |

Для проверки качества собрать представительные успешные и неудачные наблюдения и поисковые вопросы с ожидаемыми ID. Стартовый критерий — ожидаемая запись в первых пяти результатах минимум для 8 из 10 запросов и отсутствие записей за пределами фильтров. Порог Mem0 калибруется на этих примерах. При смене модели или версии Mem0 проверка повторяется.

## Отказы и обслуживание

- Начальные настройки для измерения на локальной машине — до 5 секунд на резюме, до 8 секунд на Embeddings, до 3 секунд на один вызов Qdrant и 25 секунд на всю операцию вместе с ожиданием в очереди. Каждый этап учитывает оставшийся общий бюджет. Очередь ограничить 8 ожидающими запросами. Переполнение возвращает `BUSY`.
- При временном отказе памяти раннер продолжает работу. Агент повторяет запись сохранённого краткого результата с тем же `observationId`. MVP выполняет синхронные операции и возвращает квитанцию после подтверждения Qdrant.
- В диагностике фиксировать `requestId`, операцию, длительность, результат, ошибки зависимостей и переход на шаблон. Состояние локального процесса доступно через `GET /health` на loopback. Недоступность OpenAI отображается как ограничение операций векторизации, а не как потеря записей.
- До изменения коллекции и перед обновлением Qdrant создать снимок. Проверить восстановление в отдельной коллекции. Записи хранятся между сессиями. Архивирование меняет доступность в поиске. Для MVP выбран бессрочный срок хранения. [Создание снимка Qdrant](https://api.qdrant.tech/api-reference/snapshots/create-snapshot)
- При смене профиля эмбеддингов создать новую коллекцию, перенести сохранённые поля и заново вычислить векторы. Сверить число и ID точек, ревизии, оценки и подборку контрольных запросов. Переключить настройки MCP на новую коллекцию после проверки, сохранив старую до завершения приёмки.

### Резервная копия коллекции

1. Создайте снимок через `POST /collections/{collection}/snapshots?wait=true`. Сохраните имя и контрольную сумму из ответа. [Создание снимка](https://api.qdrant.tech/api-reference/snapshots/create-snapshot)
2. Скачайте файл через `GET /collections/{collection}/snapshots/{snapshot}` в отдельное хранилище. [Скачивание снимка](https://api.qdrant.tech/api-reference/snapshots/get-snapshot)
3. Для проверки загрузите файл полем `snapshot` через `POST /collections/{newCollection}/snapshots/upload?wait=true&priority=snapshot`. Используйте новое имя и проверьте число записей, оценки и поиск перед переключением MCP на восстановленную коллекцию. [Восстановление снимка](https://api.qdrant.tech/api-reference/snapshots/recover-from-uploaded-snapshot)

## Что уточняется перед запуском

- Название и версия MCP-клиента определяют формат блока настроек, способ передачи секрета и поддерживаемую ревизию протокола. На архитектуру хранилища это не влияет.
- Доступ к Terra и Embeddings зависит от используемого проекта OpenAI API. Точный ID Terra 6.2 требуется подтвердить для этого проекта, если провайдер предоставляет его вне публичного каталога.
- Формат отчёта раннера определяется при интеграции. Раннер должен уметь сформировать стабильный `observationId`, статус выполнения и счётчики проверок для контракта записи.
