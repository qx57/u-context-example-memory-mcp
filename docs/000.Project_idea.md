Проект векторного хранилища для AI-агента

## Ограничения
- БД Qdrant
- SpringBoot для создания API, содержащее
	- эндопинт для добавления записи
	- эндпоинт для поиска записей
	- UI для управления записями (можно использовать встроенную от Qdrant)

## Назначение и описание
Хранилище нужно для хранения верных и неверных решений агента. Функция агента - создание и запуск тестов сервиса RESTful API

## Требования
- общие принципы работы в проекте, а также ссылки на документы, логи, важняе скилы и т.д. хранить в AGENTS.md
- во время работы над проектом при необходимости без дополнительных запросов обновлять AGENTS.md, скилы и документацию
- Всегда перед выполнением задачи составлять план и отправлять его на утверждение разработчику
